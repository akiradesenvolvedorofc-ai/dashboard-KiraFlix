Configure a conexão na seção Conexões.

Como a sincronização funciona

Este painel usa a tabela kira_catalog e a função save_kira_catalog já referenciadas pelo site principal. Ele não cria um banco separado.

Quando o Supabase estiver em manutenção, você pode preparar e editar os títulos nesta sessão, mas não será possível garantir a publicação no KiraFlix até a conexão voltar.

O cache temporário desta página não substitui um backup do banco.

Todos os selos do KiraFlix

Os selos são guardados no campo status de cada título. “Novo” e “Lançamento” podem expirar pelo ciclo automático configurado no site; os outros permanecem até você alterar.

Conecte o catálogo para ver todos os selos existentes.

Abas personalizadas da navegação

As abas usam o mesmo formato do KiraFlix: id, name, icon e after. Ao excluir uma aba, os títulos permanecem no catálogo, mas deixam de estar associados àquela aba.

Conecte e carregue o catálogo para editar as abas compartilhadas.

Players globais do KiraFlix

Esses quatro campos correspondem à configuração compartilhada usada pelo site principal. Variáveis aceitas: {tmdb_id}, {id}, {season_number}, {episode_number}, {season}, {episode} e {start}. Use somente fontes de vídeo que você tem autorização para incorporar.

Os players só serão aplicados aos visitantes depois de sincronizar com o Supabase.

Modo de manutenção

Quando ativado, o site principal mostra a tela de manutenção para visitantes. A alteração é compartilhada pelo registro especial __maintenance__ dentro de kira_catalog.data.tabs.

Estado desconhecido — carregue o catálogo primeiro.
A alteração requer conexão administrativa e Supabase disponível.

Supabase do KiraFlix

Use apenas a chave pública publishable/anon. Nunca coloque service_role ou chaves secretas no navegador.

A manutenção do Supabase pode impedir a conexão temporariamente.

TMDB

Você pode usar o token de leitura ou a chave API v3. O token é um segredo de acesso de leitura: evite publicá-lo em repositórios públicos. Os valores ficam apenas nesta sessão do navegador, salvo se você optar por salvar configuração local.

A gravação é local neste navegador/dispositivo, não no Supabase. O token TMDB ficará no armazenamento do navegador; não use essa opção em aparelho compartilhado. Nunca coloque credenciais no código publicado.

Esquema de integração esperado

GET /rest/v1/kira_catalog?id=eq.main&select=data e RPCs verify_kira_admin / save_kira_catalog, seguindo os nomes e parâmetros usados pelo KiraFlix existente. Se as funções ou políticas não estiverem disponíveis, o painel mostrará o erro recebido.
