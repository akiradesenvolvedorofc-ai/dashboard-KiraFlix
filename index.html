Os selos personalizados ficam salvos no registro __badges__ do catálogo.

Integração com GitHub

Conecte um repositório para sincronizar as configurações do site. O painel envia kira-settings.json ao repo, e o site o consome de raw.githubusercontent.com.

Preencha as credenciais do GitHub para habilitar.
O token precisa de escopo repo. Crie em github.com/settings/tokens. Salvo automaticamente neste navegador.
